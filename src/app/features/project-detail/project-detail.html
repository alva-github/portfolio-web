ESP32 Power Monitor

Sistema de monitorización del suministro eléctrico basado en ESP32-S3, capaz de detectar cortes de luz, registrar eventos y enviar notificaciones automáticas mediante Telegram.

Descripción del proyecto

ESP32 Power Monitor es un sistema IoT diseñado para supervisar la disponibilidad del suministro eléctrico de una instalación.

Utiliza un ESP32-S3 conectado a un módulo RTC y una memoria EEPROM para registrar los eventos de corte y recuperación, conservando su fecha y hora.

Cuando se restablece el suministro y existe conexión a Internet, el dispositivo envía una notificación mediante Telegram con la duración de la interrupción.

Funcionalidades implementadas

  • Detección de cortes eléctricos mediante GPIO.
  • Registro de eventos en memoria EEPROM.
  • Fecha y hora mediante RTC DS3231.
  • Reconexión automática a redes Wi-Fi.
  • Comprobación de conectividad a Internet.
  • Notificaciones automáticas mediante Telegram.
  • Cálculo de la duración de cada corte eléctrico.

Hardware utilizado

  • ESP32-S3-N16R8.
  • Módulo RTC DS3231.
  • Memoria EEPROM AT24C32.
  • PowerBoost 1000 Charger y batería LiPo.
  • Resistencias para el divisor de tensión.

Galería del proyecto

Prototipo funcional del ESP32 Power Monitor, con el ESP32-S3, el módulo RTC/EEPROM, el circuito de detección y la alimentación de respaldo mediante PowerBoost y batería LiPo.

Conexiones del hardware

El sistema utiliza el bus I²C para comunicarse con el reloj de tiempo real y la memoria EEPROM. La detección del suministro eléctrico se realiza mediante una entrada digital independiente.

Componente Conexión Función
RTC DS3231 GPIO 4 / GPIO 5 Fecha y hora mediante I²C
EEPROM AT24C32 GPIO 4 / GPIO 5 Almacenamiento de eventos
Divisor de tensión GPIO 6 Detección de alimentación
PowerBoost 1000 5 V / GND Alimentación de respaldo

Funcionamiento del software

El firmware está desarrollado en C++ utilizando PlatformIO y el framework Arduino. Su funcionamiento se basa en supervisar continuamente el estado del suministro eléctrico.

01

Inicialización

Configuración de GPIO, RTC, EEPROM y comunicaciones.

02

Supervisión

Lectura del GPIO 6 para detectar cambios en el suministro eléctrico.

03

Registro del corte

Al detectar una interrupción, se obtiene la fecha y hora del RTC y se registra el evento en EEPROM.

04

Recuperación del suministro

Se registra el restablecimiento y se calcula la duración del corte eléctrico.

05

Notificación

El sistema comprueba la conexión Wi-Fi e Internet y envía un informe mediante Telegram. Si falla, realiza nuevos intentos.

Resultados de las pruebas
