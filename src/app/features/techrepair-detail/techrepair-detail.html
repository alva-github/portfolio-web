TechRepair Pro

Aplicación web para la gestión de reparaciones de dispositivos electrónicos, desarrollada con Angular, Spring Boot y PostgreSQL. Incluye dashboard, operaciones CRUD, integración con iFixit y comunicación MQTT entre microservicios.

Descripción del proyecto

TechRepair Pro es una aplicación full stack desarrollada para gestionar las reparaciones de dispositivos electrónicos.

El proyecto utiliza una arquitectura basada en microservicios, separando la gestión de reparaciones del procesamiento de notificaciones mediante MQTT.

Funcionalidades implementadas

  • Registro de nuevas reparaciones.
  • Consulta, modificación y eliminación de reparaciones.
  • Actualización del estado de cada reparación.
  • Dashboard de seguimiento de reparaciones.
  • Persistencia de datos en PostgreSQL mediante JPA.
  • Consulta de guías técnicas mediante la API de iFixit.
  • Publicación de eventos mediante MQTT.
  • Recepción de eventos en el microservicio de notificaciones.
